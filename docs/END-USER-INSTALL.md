# 🖨 Scan Bridge — Quick Install (1 page)

Scan Bridge lets you scan documents straight into the web page. Install it once
on the computer that has the scanner. **~3 minutes.**

---

## Install (do this once)

**1. Download**
Open **https://scan-bridge-panel.accucia.co/download** and click the big
**Download** button (it picks the right version for your computer).

**2. Run it**
Open the downloaded file.
- On Windows, if you see **“Windows protected your PC”**, click
  **More info → Run anyway**. *(It's safe — it's our app, just unsigned.)*

**3. Let it start**
- A small **Scan Bridge icon** appears near the clock (system tray).
- Your **browser opens automatically** to the scanning page.
- *(No window to worry about — it runs quietly in the background.)*

**4. Install the scanner driver (first time only)**
If the page shows **“Scanner driver not installed”**, click
**Install NAPS2** and wait a minute. *(You never open NAPS2 — it just needs to
be installed once.)*

**5. Scan!**
Put a page on the scanner and click **⏺ Scan**. The image appears on the page.
Scan again to add more pages. Use **Download** to save them.

---

## Everyday use

- **To scan:** open the page (or right-click the tray icon → **Open Scan Bridge**).
- **To stop the app:** right-click the tray icon → **Quit Scan Bridge**.
- It starts automatically and stays ready — you normally don't touch it.

---

## If something's not right

| Problem | Do this |
|---|---|
| Page says **“Scanner connected: … (mock)”** | Click **Install NAPS2** on the page, then restart the app. |
| Page says **“not connected”** | Make sure the app is running (tray icon present) and you're on **this** computer. Open **http://localhost:3001** directly to check. |
| Scanner not found | Turn the scanner on, check the USB/WiFi cable, then click **↻ Check** on the page. |
| Need to reinstall / update | Right-click tray → **Quit**, replace the app, run it again. |
